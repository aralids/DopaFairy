# DopaFairy — Interactive 3D Simulation of the Dopaminergic Cycle

A web-based 3D simulation modeling the dopaminergic signaling cycle based on mechanistic descriptions in [Yao et al](https://doi.org/10.1371/journal.pcbi.1013508). The system visualizes neurotransmitter dynamics, enzymatic processes, and transport mechanisms in an interactive environment. Enzymatic actors are represented by character-based agents (“fairies”) to enhance conceptual clarity and educational accessibility.
